Age-structured population: submodel and "next class" association

Five age classes, newborns being class 0. Each year the animals in each class survive into the next, or die (none survive beyond class 4), and the survivors reaching classes 2 to 4 give birth. This version: as the submodel, but each class receives only from the class below, through an association; the diagram shows the relationship. In "next_class", one instance for each pair of classes where the older's number is one more than the younger's, "transfer" passes the younger's ageing_out to the older. Survival from ages 0-3: [0.6, 0.85, 0.9, 0.9]; births per animal reaching ages 2-4: [0.7, 0.85, 0.85]; starting numbers [40, 20, 16, 14, 10] (chosen for illustration: the program asks for them).

It opens with its plots and its sliders: move a slider and the model runs again.

An age-structured population: four designs in Simile

Each is a model of its own. In Simile, the Metadata panel (Widgets › Metadata) lists them too, and opens any of them beside this one.

  1. A stock per age class: conventional System Dynamics: five stocks, ageing flows between them; easy to follow, but every class repeats the same equations
  2. One submodel, five instances: the class written once, in a fixed-membership submodel; ageing passed between instances through an array every instance sees
  3. Submodel and "next class" association (this model): as the submodel, but each class receives only from the class below, through an association; the diagram shows the relationship
